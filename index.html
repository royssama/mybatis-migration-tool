MyBatis 2 XML 문법을 MyBatis 3 문법으로 변환

iBATIS/MyBatis 2의 isEqual, isNotEqual, iterate 태그를 MyBatis 3의 if, foreach 태그로 변환합니다.

변환 결과

변환 규칙

  • <isEqual property="AA_TYPE" compareValue="s001"> 는 <if test='"s001".equals(aaType)'> 로 변환합니다.
  • <isNotEqual> 은 의미에 맞게 ! 를 붙여 <if test='!"C001".equals(bbFffCode)'> 로 변환합니다.
  • <isNotEmpty property="USER_NAME"> 는 <if test='userName != null and userName != ""'> 로 변환합니다.
  • 태그의 property 값은 전체 소문자 변환 후 언더바 다음 문자만 대문자로 바꾸고 언더바를 제거합니다.
  • SRCTYPE 는 srctype, AAA_LIST 는 aaaList 로 변환합니다.
  • iterate 내부의 리스트 컬럼명은 camelCase로 변경하지 않습니다.
